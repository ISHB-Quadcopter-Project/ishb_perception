# Perception

## How to Navigate this Repo
Navigate to the scripts folder. Here you will find three python files:
1) Accumulator.py -Node to down sampling LiDAR point cloud for efficiency
2) TreeFinder.py - Node to cluster multiple z-slices using DBSCAN, and applying Principal Component Analysis (PCA) to a neighborhood of points from a K-d tree, to identify trees
3) Common.py - Common use helper functions
